# Ongaku Studio User Manual

This manual explains how to make music with Ongaku Studio, from your first project to mixing, session players and the Ongaku plug-ins. Each chapter explains what a feature is and when you'd use it, then shows you how, step by step.

If you're new to music apps like this, start with Chapter 1. It introduces the words the rest of the manual uses: project, track, region, playhead, cycle and so on. After that, read the chapters in any order.

## Conventions

- **Bold** text is a label you'll see on screen. **Track › New Audio Track** means: open the **Track** menu and choose **New Audio Track**.
- Keyboard shortcuts use the Mac's symbols: ⌘ Command, ⌥ Option, ⇧ Shift, ⌃ Control, ⌫ Delete. ⌥⌘U means hold Option and Command and press U.
- Many single-key shortcuts, such as Space to play or E to show the editor, are shown in the menus like any other shortcut, but only work while the project window is in front and you aren't typing in a text field. [Chapter 10](10-key-commands.md) explains how this works.
- **Settings › General** means the General tab of the Settings window. Open it with **Ongaku Studio › Settings…** (⌘,).
